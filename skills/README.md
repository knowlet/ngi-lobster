# NGI Lobster plugin skill root

This root is reserved for native OpenClaw plugin-installed skills and setup guidance.

## Project goal

The repo goal is to turn NGI Lobster into an installable OpenClaw plugin product where:

- source plugins ingest and normalize evidence
- runtime computes live thesis truth from artifacts
- OpenClaw is the install and tool surface
- delivery remains downstream of runtime truth

Current state:
- native OpenClaw install wrapper exists
- core runtime still lives in `lobster-intel/`
- install guide lives in `docs/INSTALL_OPENCLAW.md`
